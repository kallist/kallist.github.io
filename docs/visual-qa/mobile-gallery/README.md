# Historical mobile gallery QA

These captures document the earlier mobile-only implementation. That implementation had a separate phone reel and an unchanged desktop artwork band. The shared exhibition ribbon supersedes it, so the old capture script was retired. For current reproducible visual QA, use `node scripts/capture-exhibition-gallery.mjs` and `docs/visual-qa/exhibition-gallery/`.

These are Chromium viewport captures from a local static build. They are not physical phone or production evidence.

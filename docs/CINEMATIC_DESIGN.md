# Kallist — living archive / 2026-10-22

## Goal and resolved design tree

Audience: recruiters and technical interviewers who need a quick identity, a useful work sample and a direct next step, plus visitors who want to explore the visual work. The user delegated all decisions and explicitly requested no questions. The grilling frontier was therefore resolved by environmental evidence, three independent audits and explicit design choices, rather than an invented user interview.

- Success → recognizable authorship, clear AI application / Agent engineering focus, truthful evidence and direct resume/contact access. No design can establish or promise a hiring outcome.
- Identity → keep kallist, the supplied ink portrait, paper/graphite/terracotta, measured rails and the existing Möbius Context Loop. Give the visual identity one strong opening composition; let reading surfaces remain quiet.
- Reading path → identity + 2027 class + direct actions → fast work index → existing project scenes / case details → screening room → education / method / visual archive / contact. Navigation offers direct access at every stage.
- Work → retain all five projects and original routes, factual limits and unfavourable evaluation findings. The index exposes purpose, not invented impact numbers.
- Motion → controlled arrival, linked work selection / image change and one film stage; no forced waiting, scroll hijack, automatic audio or new heavyweight rendering system. Retain the existing Canvas 2D loop and native scene observer.
- Media → all three user-supplied files, with a bounded 1080p comparison derivative and a 48-second Singularity excerpt excluding an unsupported festival title. Preserve the source-credited Gemini ending and state provenance without inferring exclusive authorship.
- Delivery → feature branch based on current merged main; local/hosted validation and reviewable Draft PR. No merge or deployment is inferred from permission to redesign.

## Reference audit and trade-offs

References actually browsed: [bleibtgleich](https://bleibtgleich.dev/) and [Daniel Spatzek](https://www.danielspatzek.com/home/). Their transferable strengths are hierarchy, density changes and an interaction that changes the work being discussed. Their logos, work, scene assets and distinctive interaction metaphors are not copied.

Three independent read-only audits found: the existing opening obscures career identity and resume/contact; project screenshots require reading very small UI; repeated monumental sections and a persistent loop flatten the pace. The base has a valuable hand-drawn, evidence-conscious identity worth retaining. Current baseline is merged main `4e07bcfeafe7192aa099758b744c7f74c75270dd`.

## Direction exploration

Three first-screen studies are archived in `docs/design/cinematic/directions/`. They share actual content but explore different compositions: A, Living index (overscale identity + source portrait + direct actions); B, Film edit (moving-image first); C, Field notes (columnar editorial cover). A is selected for balancing an immediate personal identity with a fast recruitment path. B makes the films look like the primary profession; C is coherent but closest to the existing cover. The comparison is self-selected under the user's delegated decision authority, not user research.
